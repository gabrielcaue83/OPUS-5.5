# Opus 5.5

Landing page imersiva do Opus 5.5. A câmera surfa um trilho de luz pelo interior da rede neural, e um único enxame de partículas monta cada estação: portal, mente, árvore de inferência, olho multimodal, camadas neurais, órbita de agentes, monólitos e núcleo.

## Como abrir

Abra o `index.html` no navegador. É um arquivo único, sem build: as bibliotecas (Three.js, GSAP + ScrollTrigger e Lenis) e as fontes vêm de CDN, então é preciso estar conectado à internet.

- `index.html` — a página
- `teste.html` — abre a página no modo tour, que percorre todas as estações sozinho (útil para apresentar)

## Antes de publicar

- Os números (latência, parâmetros, contexto etc.) são ilustrativos.
- O endereço da API (`api.opus55.ai`) e o link "Documentação completa" são provisórios.
- O formulário de acesso só mostra a confirmação na tela; conecte o envio ao seu backend no trecho marcado no código.
